# iOS 证书生成指南

本指南将帮助你从零开始创建 iOS 开发证书并配置到项目中。

## 📋 前提条件

- ✅ Apple Developer 付费账号（$99/年）
- ✅ macOS 系统
- ✅ 管理员权限

## 🔐 步骤 1：创建证书签名请求 (CSR)

### 方法 1：使用钥匙串访问（推荐）

1. 打开"钥匙串访问"应用
   ```bash
   open "/Applications/Utilities/Keychain Access.app"
   ```

2. 在菜单栏选择：**钥匙串访问 → 证书助理 → 从证书颁发机构请求证书**

3. 填写信息：
   - **用户电子邮件地址**：你的 Apple ID 邮箱
   - **常用名称**：你的名字或公司名（例如：TokLink Development）
   - **CA 电子邮件地址**：留空
   - **请求**：选择 **存储到磁盘**
   - **让我指定密钥对信息**：勾选

4. 点击"继续"，保存为：`CertificateSigningRequest.certSigningRequest`

5. 密钥对信息：
   - **密钥大小**：2048 位
   - **算法**：RSA

### 方法 2：使用命令行

```bash
# 创建私钥
openssl genrsa -out ios_development.key 2048

# 创建 CSR
openssl req -new -key ios_development.key -out CertificateSigningRequest.certSigningRequest -subj "/emailAddress=your@email.com/CN=TokLink Development/C=HK"
```

## 🌐 步骤 2：在 Apple Developer 创建证书

1. 访问 Apple Developer 网站
   ```bash
   open https://developer.apple.com/account/resources/certificates/list
   ```

2. 点击 **+** 按钮创建新证书

3. 选择证书类型：
   - **开发环境**：选择 `Apple Development`
   - **生产环境**：选择 `Apple Distribution`（用于 App Store）

4. 点击"Continue"

5. 上传刚才创建的 CSR 文件（`CertificateSigningRequest.certSigningRequest`）

6. 点击"Continue"

7. 下载证书：点击"Download"保存为 `ios_development.cer`

## 💾 步骤 3：安装证书到钥匙串

### 自动安装

双击下载的 `ios_development.cer` 文件，会自动安装到钥匙串。

### 手动安装

```bash
# 导入证书到登录钥匙串
security import ios_development.cer -k ~/Library/Keychains/login.keychain-db
```

验证证书已安装：
```bash
# 查看已安装的开发证书
security find-identity -v -p codesigning
```

你应该看到类似输出：
```
1) ABC123DEF456 "Apple Development: your@email.com (TEAM_ID)"
```

## 📦 步骤 4：导出证书为 .p12 文件

### 使用钥匙串访问

1. 打开"钥匙串访问"
   ```bash
   open "/Applications/Utilities/Keychain Access.app"
   ```

2. 在左侧选择：**登录 → 我的证书**

3. 找到刚才安装的证书（名称如：`Apple Development: your@email.com`）

4. **展开证书**，你会看到下面有一个对应的私钥

5. **右键点击证书**（不是私钥）→ 选择 **导出**

6. 保存设置：
   - **文件格式**：个人信息交换 (.p12)
   - **保存位置**：`ios/certificates/development.p12`
   - **密码**：`toklink2025`（团队统一密码）
   - **验证密码**：再输入一次 `toklink2025`

7. 可能需要输入 Mac 登录密码以允许导出

### 使用命令行

```bash
# 导出证书和私钥为 .p12 格式
security export -k ~/Library/Keychains/login.keychain-db \
  -t identities \
  -f pkcs12 \
  -o ios/certificates/development.p12 \
  -P toklink2025
```

## 📱 步骤 5：创建 App ID

如果还没有创建 App ID：

1. 访问 App IDs 页面
   ```bash
   open https://developer.apple.com/account/resources/identifiers/list
   ```

2. 点击 **+** 创建新的 Identifier

3. 选择 **App IDs** → Continue

4. 选择 **App** → Continue

5. 填写信息：
   - **Description**：TokLink
   - **Bundle ID**：Explicit（明确的）
   - **Bundle ID 值**：`com.xiaowang.ushop`

6. **Capabilities**：勾选你需要的功能
   - Push Notifications（如果需要推送）
   - Sign in with Apple（如果需要）
   - 等等

7. 点击"Continue" → "Register"

## 📲 步骤 6：创建 Provisioning Profile

1. 访问 Profiles 页面
   ```bash
   open https://developer.apple.com/account/resources/profiles/list
   ```

2. 点击 **+** 创建新的 Profile

3. 选择类型：
   - **开发环境**：选择 `iOS App Development`
   - **Ad Hoc 分发**：选择 `Ad Hoc`（用于测试分发）
   - **App Store**：选择 `App Store`（用于发布）

4. 点击"Continue"

5. 选择 **App ID**：选择 `com.xiaowang.ushop`

6. 点击"Continue"

7. 选择 **证书**：勾选刚才创建的开发证书

8. 点击"Continue"

9. **（仅开发/Ad Hoc）** 选择设备：勾选需要安装的设备

10. 点击"Continue"

11. **Profile Name**：输入名称（例如：`TokLink Development`）

12. 点击"Generate"

13. 下载 Profile：点击"Download"保存为 `development.mobileprovision`

14. 移动到项目：
    ```bash
    mv ~/Downloads/TokLink_Development.mobileprovision ios/certificates/development.mobileprovision
    ```

## ✅ 步骤 7：验证配置

检查证书文件：
```bash
ls -la ios/certificates/
```

应该看到：
```
development.p12
development.mobileprovision
```

查看 .p12 信息：
```bash
openssl pkcs12 -info -in ios/certificates/development.p12 -noout
# 密码：toklink2025
```

查看 Provisioning Profile 信息：
```bash
security cms -D -i ios/certificates/development.mobileprovision
```

## 🚀 步骤 8：测试构建

```bash
# 配置证书
make setup-ios-certs

# 构建 IPA
make build-ipa
```

## 📝 常见问题

### Q1: 证书已过期怎么办？

证书有效期为 1 年。过期后：
1. 重新生成 CSR
2. 在 Apple Developer 创建新证书
3. 导出新的 .p12 文件
4. 更新 Provisioning Profile（添加新证书）
5. 替换项目中的证书文件

### Q2: 多个开发者如何共享证书？

方法 1（推荐）：
- 将 development.p12 和 development.mobileprovision 提交到 Git
- 团队成员拉取后运行 `make setup-ios-certs`

方法 2：
- 每个开发者创建自己的证书
- 在 Provisioning Profile 中添加所有证书
- 每个开发者使用自己的证书

### Q3: 忘记 .p12 密码怎么办？

需要重新导出 .p12 文件并设置新密码。

### Q4: 找不到证书对应的私钥？

确保：
1. CSR 是在当前 Mac 上生成的
2. 证书是使用该 CSR 创建的
3. 证书已正确导入到"登录"钥匙串

### Q5: 真机运行报错 "Untrusted Developer"？

在 iOS 设备上：
1. 打开 **设置 → 通用 → VPN 与设备管理**
2. 找到你的开发者证书
3. 点击 **信任**

## 🔄 证书类型对照表

| 证书类型 | 用途 | 有效期 | 是否可共享 |
|---------|------|--------|-----------|
| Apple Development | 开发和真机测试 | 1 年 | ✅ 可共享 |
| Apple Distribution | App Store 发布 | 1 年 | ⚠️ 谨慎共享 |
| Apple Push Services | 推送通知 | 2 年 | ✅ 可共享 |

## 📌 重要提醒

- ✅ **备份私钥**：.p12 文件包含私钥，务必妥善保管
- ✅ **统一密码**：团队使用统一的 .p12 密码（当前：`toklink2025`）
- ⚠️ **不要泄露**：虽然可以提交到内部 Git，但不要公开
- 🔄 **定期更新**：证书过期前 1 个月开始准备更新
- 📱 **设备管理**：及时添加新的测试设备到 Provisioning Profile
